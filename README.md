# مشروع جاهز لتشغيل استدعاء نموذج ذكاء صناعي

هذا المستودع يحتوي على سكربت Python بسيط لاستدعاء خدمة توليد نصوص (AI) ��بر HTTP.

الملفات المضافة/المحدّثة:
- main.py  : نسخة محسّنة لقراءة المتغيرات من البيئة، تسجيل أخطاء، وإعادة محاولة عند فشل الشبكة.
- requirements.txt : إصدارات مثبتة للحزم المطلوبة.
- .env.example : مثال لملف المتغيرات البيئية.
- .gitignore : تجاهل ملفات البيئة وملفات بايت كود.

طريقة الإعداد والتشغيل
1) انسخ .env.example إلى .env واملأ KEY_ONE بقيمة مفتاح الـ API الخاص بك:
   cp .env.example .env
   ثم عدّل .env وأدخل KEY_ONE

2) ثبّت المتطلبات:
   python3 -m pip install -r requirements.txt

3) شغّل السكربت:
   python3 main.py

   أو أرسل سؤالاً مخصصاً:
   python3 main.py "اكتب رسالة ترحيب قصيرة"

ملاحظات
- تأكد من أن API_URL و USE_KEY_IN_QUERY مناسبان لمزود الخدمة الذي تستخدمه.
- إذا كان مزود الخدمة يتطلب Authorization: Bearer <token> ضع USE_KEY_IN_QUERY=false في .env.
- راجع سجلات التشغيل (الـ logs) للحصول على تفاصيل الأخطاء.

إذا رغبت، أستطيع:
- تعديل بنية الطلب (JSON body) لتتناسب مع API محدد (مثل OpenAI أو Google GenAI) إذا أخبرتني بخدمة الـ API التي تستخدمها.
- إضافة اختبار محلي أو سكربت تشغيل في Docker.
